
## Goal
Helping user taking their journal, make them open up their mind


### Base feature

#### Chat assist

The role is to only listen encourage reflection, and help the user express themselves

##### Journaling from a template
- The chatbot should take the template topic seriously for user to not stay out of topic, like in a `therapy prepare prompt` or in a `lesson prompt`


##### Journaling from no template
- User can freely talk about any topic, but the chatbot will act as only a listener, not providing any clinical diagnoses or help 

#### Speech message input




#### Autofill
There can be 2 case

**No text appear in the prompt or not going toward a specific topic**
- Generate a low opacity text adding a general question relating to the topic or recent journal

**Input have appear and lending toward a specific topic**
- Add follow up question about what user writing


The question should be generated as user asking them self
